# Calisthenics Evolution — releases

Este repositório público contém somente versões de distribuição do aplicativo. O código-fonte é mantido separadamente.

## Instalação

Abra a página [Releases](../../releases), escolha uma versão publicada e baixe o APK. No Android, abra o arquivo e confirme a instalação; pode ser necessário autorizar a instalação a partir do aplicativo usado para abrir o arquivo. Atualizações preservam os dados quando o pacote e o certificado de assinatura Android são compatíveis.

## Publicação

Cada versão de produção deve incluir um APK assinado, `update.json` e `update.sig` (assinatura do manifesto). Os arquivos de chave privada e o código-fonte não pertencem a este repositório. Ainda não há uma versão publicada até que o mantenedor publique um APK verificado.
